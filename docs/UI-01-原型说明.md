## 2 视图映射表（原型 hash ↔ 线上 URL）

原型是 hash 路由 SPA；线上是多页站点（MPA），5 个真实页面 + 404。「改造对照」视图是原型专属，不进线上。

| 原型路由 | 原型视图 | 线上 URL | 承载 |
|---|---|---|---|
| `#/home` | 首页（hero + 精选 + 热门 + 最近更新 + 分类卡片） | `/` | 主题 `index.ejs`（取代 collect.js 停用的动态主页） |
| `#/archive`（`?cat=` `?tag=`） | 归档（分组 + 真过滤） | `/archives/` | 主题 `archive.ejs` |
| `#/tags` | 标签云 | `/tags/` | 主题标签视图（collect.js tags/categories 统计职责并入呈现） |
| `#/article/:id` | 文章页 | `/posts/:abbrlink.html` | 主题 `post.ejs`；abbrlink = crc32(title) |
| `#/about` | 关于（PROFILE 数据驱动） | `/about/` | 主题 `page.ejs` |
| `#/compare` | 标题去编号改造对照 | **不进线上** | 原型专属演示页 |
| 未知 hash | 404 视图 | `/404.html` | 主题 `404.ejs` |

分类树侧栏、TOC、顶栏为全视图共用骨架，线上以 partials 实现。

## 4 设计 tokens

### 4.1 色板（CSS 变量，light/dark 双主题）

| 变量 | Light | Dark | 用途 |
|---|---|---|---|
| `--bg` / `--bg-soft` / `--bg-mute` / `--bg-code` | `#ffffff` / `#f6f8fa` / `#eef0f4` / `#f6f8fa` | `#0d1117` / `#151b23` / `#1c232e` / `#161b22` | 背景分层 |
| `--text` / `--text-2` / `--text-3` | `#1f2328` / `#59636e` / `#818b98` | `#e6edf3` / `#9198a1` / `#6e7681` | 正文/次级/弱化文字 |
| `--border` / `--border-strong` | `#e4e7ec` / `#d1d5db` | `#2d333b` / `#444c56` | 边框 |
| `--accent` / `--accent-soft` | `#0969da` / rgba(9,105,218,.08) | `#539bf5` / rgba(83,155,245,.12) | 强调/链接/激活态 |
| `--green` / `--amber` / `--amber-bg` | `#1a7f37` / `#9a6700` / `#fff8c5` | `#57ab5a` / `#c69026` / rgba(198,144,38,.12) | 成功/警示/callout |
| `--radius` / `--shadow` | `8px` / 0 1px 3px rgba(31,35,40,.08) | 同左 / rgba(0,0,0,.4) | 圆角/阴影 |
| `--sidebar-w` / `--toc-w` / `--maxw` | `264px` / `216px` / `780px` | 同左 | 骨架尺寸 |

主题切换机制：`html[data-theme="light|dark"]` 变量整组覆盖（dark 覆盖 `[data-theme="dark"]`）。

### 4.2 字体

- 正文：`-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`；15px / line-height 1.7
- 等宽：`"Cascadia Code", Consolas, "JetBrains Mono", monospace`（代码块 13px、行号、kbd、计数）

### 4.3 断点

| 断点 | 行为 |
|---|---|
| ≤1100px | 右侧 TOC 隐藏 |
| ≤860px | 移动端主断点：侧栏改抽屉、顶栏导航隐藏、☰ 出现、触摸目标 44px、link-grid 单列 |
| ≤560px | 排版紧凑化：hero 字号收缩、列表日期换行、作者卡/链接行单列 |

## 5 原型与线上差异（有意为之，非遗漏）

| # | 差异 | 原因 |
|---|---|---|
| 1 | SPA → MPA：hash 路由改为 5 个真实页面 + 404 | Hexo 静态生成天然多页；真实 URL 利于 SEO 与外链稳定（映射见 §2） |
| 2 | 热门排行数据：原型 MOCK_VIEWS → 线上暂沿用 MOCK + **可见「示例数据」标注**；接真实访问统计记 TODO（本轮不加统计） | 统计属 Out of scope（URD-01 §2.2、SDD-01 ADR-4） |
| 3 | 「改造对照」视图不进线上 | 原型专属演示页（标题去编号建议已另行流转到内容层整改） |
| 4 | 数据：原型内嵌 DATA 数组 → 线上来自 collect.js 产物（_posts、search.json、统计页） | 原型示例数据仅供演示；搜索数据源统一 /search.json（SDD-01 ADR-3） |
| 5 | SEO：原型无 meta/OG → 线上 `head` partial 落 title、description、OG 标签 | 公开站点的搜索与分享卡片需要 |
| 6 | 「UI 原型」角标、示例 footer 不进线上 | 仅演示标识 |
| 7 | 字数「约 X 分钟」：原型写死 → 线上由主题按正文估算 | 数据真实性 |
