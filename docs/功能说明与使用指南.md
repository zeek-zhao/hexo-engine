> 受控文档 OB-ENG-WEB-FEATURES v1.0（2026-11-15）。对应实现：hexo-engine 主题 `themes/zeek` + 构建流水线 `bin/collect.js` + 质量门禁 `scripts/check-pages.js` / `tests/bdd-runner.js`。功能变更须同步修订本文件与 URD/SDD。

## 2. 常用操作

### 2.1 写一篇新文章
1. 在 vault 对应目录建 md（目录 = 细分分类），frontmatter 按 SOP-07 填写：`title`（全库唯一）、`categories: [细分]`、`tags: [2~3 个]`、`description`、`date`、`published: true`、`status: published`。
2. 等每日 2:00 UTC 全量构建，或推 ai-obsidian 触发即时发布（2~3 分钟）。
3. 校验：站内 ⌘K 搜标题；CI run 绿灯即发布成功。

### 2.2 下线 / 暂时隐藏一篇文章
frontmatter 改 `published: false`（或 `status: draft`），提交后下次构建自动从站点消失，链接变 404。注意：改 `title` 会改变短链 URL（abbrlink = crc32(title)），正式发布后不要改标题。

### 2.3 搜索
- 快捷键：`Ctrl/⌘+K` 或 `/` 唤起；`↑↓` 选择、`Enter` 打开、`Esc` 关闭。
- 支持多关键词（空格分隔），匹配范围 = 标题 + 描述 + 标签 + 分类 + 正文前 1200 字。
- 结果显示命中片段（正文命中时展示上下文）；标题命中的排在前面。

### 2.4 评论（读者侧）
文章底部「评论」区，用 GitHub 账号登录后发言；讨论集中在 zeek-zhao.github.io 仓库的 Discussions。首次使用需在 giscus 授权 GitHub App 权限。

### 2.5 RSS 订阅（读者侧）
订阅地址：`https://zeek-zhao.github.io/atom.xml`。任何 RSS 阅读器（Feedly、Inoreader、NetNewsWire 等）添加该地址即可，最多显示最近 20 篇的标题与摘要，点进去读全文。

### 2.6 调整分类归属
改 `90-OB工程管理/方案/06-分类映射.json`（细分 → 领域映射 + 图标表），提交后下次构建生效。**不要**改 frontmatter 的 categories 来调领域——领域是构建期注入的。

### 2.7 启用背景音乐 / 访问统计
`_config.yml` 的 `zeek` 段：
```yaml
zeek:
  bgm: "https://…/bgm.mp3"   # 填音频直链即启用页脚播放按钮；空=关闭
  analytics: "ga4-G-XXXXXXXXXX"          # 或 "goatcounter-你的站点码"；空=关闭
```

## 4. 本地开发

```powershell
npm ci                      # 装依赖
npm run build               # collect → hexo clean+generate → check-pages → BDD
npx hexo server             # 本地 http://localhost:4000 预览
npm run test:bdd            # 只跑 BDD 功能测试
```
注意：`hexo generate` 不会清理旧产物，必须先 `hexo clean`（`npm run build` 已串好）。
